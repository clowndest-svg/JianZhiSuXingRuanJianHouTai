# 轻塑 App 后台管理系统

主应用是 `JiaZhiSuXianApk`（轻塑 · 减脂塑形 App，FastAPI + SQLite + WebView APK）。
本仓库是它的**旁路后台**：运营者看数据、处理反馈与举报、做合规读取，
以及把三件过去只能在 SSH 里手敲的事搬进界面（抬强更门、触发备份、看服务健康）。

**后台不在主链路上。** Directus 或运维 API 全挂，App 照常跑；这是本设计的硬要求。

## 组成

```
Directus 11（容器，127.0.0.1:8055）  数据控制台：列表 / 筛选 / 低风险字段编辑
ops/admin_api.py（systemd，127.0.0.1:8100） 运维 API：注销 / 封号 / 重置密码 / 撤销会话 /
                                              抬门 / 备份 / 计数聚合 / 审计
ops/console.html                          运维页（单文件，不引外部 CDN）
nginx qingsu-tls                          对外只暴露 /admin/ 与 /ops/，BasicAuth + 限流
```

分界面的判据只有一条：**这个操作做错了，能不能靠"改回去"救回来？**
能 → Directus；不能 → 运维 API（有显式确认、有审计、有防呆）。

## 怎么看

```
https://124.220.54.64/admin/    Directus 控制台（策略账号）
https://124.220.54.64/ops/      运维页（高危动作）
```

账号口令不在本仓库。口令、`KEY`/`SECRET`、`OPS_TOKEN` 只落服务器上的
`/opt/qingsu/admin/*.json`（`chmod 600`，属主 root）。
仓库里**只有 `deploy/env.example` 的键名与说明**。

## 三条要先知道的实测结论

1. **超级管理员绕过一切字段权限**（实测 `fields=*` 原样返回 `password_hash` 等 5 列）。
   所以超管口令只用于建号与修复，日常必须用策略账号；策略账号的字段白名单实测有效。
2. **策略与权限只能用 SQL 播种**，`POST /policies` 对超管返回 403；播完必须重启容器才生效。
3. **12 张表在控制台里读不到**（`follows`、`post_likes`、`water_logs` 等没有单列整数主键）。
   它们的数字一律由运维 API 现算，不在前端拼 COUNT。

完整清单见 docs/03 §3。

## 与主应用的关系

主应用侧只为后台改了 4 处（都在 docs/04 §4，每处可单独回退）：
`users` 加封号两列并在 `get_current_user` 的**同一条查询**里判定（C-1）、
数据目录权限 `2770/660`（C-2b）、密钥挪出挂载目录（C-4）、nginx 加两段 location（C-3）。
