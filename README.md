# 轻塑 App 后台管理系统

2026-10-20 更新：运维台增加「域名与发布」「邮件接入」，展示域名 HTTPS 实测结果、证书剩余时间、当前版本、带时间戳的监控读数和浏览器推送订阅总量。邮件账号由管理员在界面配置，授权码不会回显或进入审计；支持465 SSL与587 STARTTLS，检查只验证连接和认证，不发送邮件。尚未提供真实SMTP账号时应保持关闭。

退出运维台后会隐藏所有业务面板并清空令牌与邮件授权码输入。敏感列脱敏补充了推送订阅地址、会话哈希、订阅密钥和目标邀请码哈希，同时修复审计结果被原始字段覆盖的问题。

主应用是 `JiaZhiSuXianApk`（轻塑 · 减脂塑形 App，FastAPI + SQLite + WebView APK）。
本仓库是它的**旁路后台**：运营者处理反馈与举报、查用户与内容、做合规读取，
以及把三件过去只能在 SSH 里手敲的事搬进界面（抬强更门、触发备份、看服务健康）。

**后台不在主链路上。** Directus 或运维 API 全挂，App 照常跑；这是本设计的硬要求。常用工单与审核流程可在 /ops/ 内完成，
不需要从列表跳到另一个系统；Directus 保留给高级数据查询和低频维护。

## 组成

```
Directus 11（容器，172.17.0.1:8055）  高级数据控制台：查询 / 筛选 / 低频维护
ops/admin_api.py（systemd，172.17.0.1:8100） 运维 API：注销 / 封号 / 重置密码 / 撤销会话 /
                                              抬门 / 备份 / 工单回复 / 举报处置 / 计数聚合 / 审计
ops/console.html                          桌面与手机自适应工作台（单文件，不引外部 CDN）
nginx qingsu-tls                          对外只暴露 /admin/ 与 /ops/，BasicAuth + 限流
```

固定工作流走 /ops/ 的白名单 API：读写都要认证、状态更新带预期旧状态、内容下架是软删除并同事务审计。
Directus 供高级查询和低频维护使用；账号封禁、注销、重置、强更门和备份仍保留强确认。

仓库里**只有 `deploy/env.example` 的键名与说明**。

## 三条要先知道的实测结论

1. **超级管理员绕过一切字段权限**（实测 `fields=*` 原样返回 `password_hash` 等 5 列）。
   所以超管口令只用于建号与修复，日常必须用策略账号；策略账号的字段白名单实测有效。
2. **策略与权限只能用 SQL 播种**，`POST /policies` 对超管返回 403；播完必须重启容器才生效。
3. **12 张表在控制台里读不到**（`follows`、`post_likes`、`water_logs` 等没有单列整数主键）。
   它们的数字一律由运维 API 现算，不在前端拼 COUNT。

完整清单见 docs/03 §3。
